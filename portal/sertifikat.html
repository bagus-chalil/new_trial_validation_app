Pasang sertifikat QAC

Cukup sekali per perangkat. Setelah terpasang, peringatan "Tidak aman" hilang dari semua aplikasi QAC, dan portal bisa diinstal sebagai aplikasi di desktop maupun HP.

Unduh sertifikat (qac-root-ca.crt)

Windows (Chrome / Edge)

  1. Buka file qac-root-ca.crt yang diunduh, lalu klik Install Certificate.
  2. Pilih Local Machine (atau Current User kalau tidak punya akses admin).
  3. Pilih Place all certificates in the following store → Browse → Trusted Root Certification Authorities.
  4. Selesaikan wizard, lalu tutup dan buka lagi browser.

Android

  1. Unduh file sertifikat di atas.
  2. Buka Settings → Security → Encryption & credentials → Install a certificate → CA certificate. Nama menu bisa sedikit berbeda antar merek HP.
  3. Pilih file qac-root-ca.crt, lalu konfirmasi.

iPhone / iPad

  1. Buka halaman ini di Safari, lalu unduh sertifikat. Pilih Allow.
  2. Buka Settings → Profile Downloaded → Install.
  3. Wajib: buka Settings → General → About → Certificate Trust Settings, lalu aktifkan QAC Internal Root CA.

Setelah itu: instal portal sebagai aplikasi

  1. Chrome / Edge desktop: klik ikon Install di ujung kanan address bar.
  2. Android Chrome: menu ⋮ → Install app / Add to Home screen.
  3. iPhone Safari: tombol Share → Add to Home Screen.

Sertifikat ini hanya berlaku untuk server internal QAC. Kalau ada kendala saat memasang, hubungi tim IT.
