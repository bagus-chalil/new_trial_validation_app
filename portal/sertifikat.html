Pasang sertifikat QAC

Cukup sekali per perangkat. Setelah terpasang, peringatan "Tidak aman" hilang dari semua aplikasi QAC, kamera (OCR IPC) bisa dipakai, dan portal bisa diinstal sebagai aplikasi.

Windows (Chrome / Edge)

  1. Klik tombol di atas. Kalau browser bertanya, pilih Keep / Simpan.
  2. Buka file setup-sertifikat-qac.cmd. Kalau muncul "Windows protected your PC", klik More info → Run anyway.
  3. Klik Yes pada peringatan keamanan Windows.
  4. Tutup semua jendela Chrome / Edge, lalu tekan tombol apa saja di jendela setup. Portal terbuka lagi dengan gembok normal.
  5. Klik Install Aplikasi di portal.

Tidak butuh akses admin. Sertifikat dipasang untuk akun Windows Anda saja.

Cara manual (kalau file setup diblokir)
  1. Unduh qac-root-ca.crt, buka filenya, lalu klik Install Certificate.
  2. Pilih Current User → Next.
  3. Pilih Place all certificates in the following store → Browse → Trusted Root Certification Authorities. Jangan pilih "Automatically select the certificate store", karena sertifikat akan masuk ke tempat yang salah dan peringatan tidak hilang.
  4. Finish → klik Yes pada peringatan keamanan, lalu tutup dan buka lagi browser.

Android (Chrome)

Download Sertifikat

1. Pasang sertifikat

  1. Tap tombol di atas. File qac-root-ca.crt tersimpan di Downloads.
  2. Buka Settings, cari "CA certificate" di kolom pencarian Settings. Atau lewat Security → More security settings → Encryption & credentials → Install a certificate → CA certificate. Nama menu berbeda sedikit per merk.
  3. Tap Install anyway, lalu pilih file qac-root-ca.crt dari Downloads.
  4. Kalau diminta, buat PIN / pola kunci layar dulu. Android mewajibkan ini.

2. Install aplikasi

  1. Tutup Chrome sepenuhnya (geser dari daftar aplikasi terbuka), lalu buka lagi portal.
  2. Pastikan halaman ini menampilkan "Sertifikat sudah terpasang".
  3. Di portal, tap Install Aplikasi. Ikon QAC muncul di home screen.

Membuka file .crt langsung dari notifikasi download tidak akan berhasil di Android 11 ke atas. Harus lewat menu Settings di atas.

iPad / iPhone

Download Sertifikat

1. Pasang sertifikat

  1. Buka halaman ini di Safari (bukan Chrome), lalu tap tombol di atas. Pilih Allow, lalu Close.
  2. Buka Settings. Di bagian atas muncul Profile Downloaded, tap lalu Install (masukkan passcode) → Install → Done. Kalau tidak muncul: General → VPN & Device Management.
  3. Wajib, sering terlewat: Settings → General → About → Certificate Trust Settings, aktifkan QAC Internal Root CA → Continue.

2. Tambahkan ke home screen

  1. Tutup lalu buka lagi Safari, buka portal.
  2. Tap tombol Share (kotak dengan panah ke atas) → Add to Home Screen → Add.

iPad tidak punya tombol install otomatis; langkah Share di atas adalah satu-satunya cara.

Sertifikat ini hanya berlaku untuk server internal QAC. Kalau ada kendala saat memasang, hubungi tim IT.
