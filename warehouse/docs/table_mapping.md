## Rules applied

- Columns matching `/(^|_)(password|password_hash|remember_token|token|secret|ip_address|user_agent)$/i` are never copied (password hashes, tokens, IP, user agent).
- `activity_logs` / `audit_logs` `old_data` and `new_data` are set to NULL when they mention password / token / secret (found: 51 `activity_logs` rows, module USER, contain a `password_hash` key).
- Trial-side links are by **email text** (`created_by`, `approved_by`, `pending_with`, `reviewer_email`, `uploaded_by`, `audit_logs.user_email`) — resolved to `users.id` in `staging`, not here.
- `raw` keeps MySQL-derived types (e.g. `tinyint` → `smallint`, `json` as exposed by mysql_fdw); casting to boolean/jsonb happens in `staging`.
